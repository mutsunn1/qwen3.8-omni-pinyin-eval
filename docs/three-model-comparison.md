## 0. 总览

| 维度 | **Qwen3.8-Omni** | **SDHY P0-v2** | **讯飞 ISE（流式评测）** |
|---|---|---|---|
| 类型 | 云端多模态大模型（闭源 API） | 开源/私有声学评测栈（自托管） | 商用语音评测 API（闭源） |
| 核心结构 | Omni 大模型，文本/音频输入 → 文本/JSON | 冻结 XLSR-zh（317M）+ M1 音素 CTC 头 + X2 声/韵对齐头 + 质心/VOT | 未公开（商用引擎） |
| 训练数据 | 未公开 | AISHELL-1 训练小头；编码器 XLSR-53 中文 fine-tune | 未公开 |
| 原生任务 | 通用对话/识别/理解（自由识别靠 prompt） | **已知 target 的发音评测**（覆盖率/错误定位） | **已知 reference 的发音评测**（字词句篇章打分） |
| 自由识别（无参考） | **✅ 一次调用出 initial/final/tone** | △ 需适配（对齐头当识别器，效果差） | **❌ 不支持**（必须给参考文本） |
| 检测（target 一致性） | ✅ 可派生（自由识别+比较，F1 0.922） | △ 可派生（F1 0.731） | ✅ 原生（打分阈值，F1 0.914） |
| 输出可解释性 | 文本/JSON（无置信度） | 分数/margin/VOT/声调形状（产品链路） | **逐音素 error type、声韵调分（最强）** |
| 部署 | 调 API（OpenAI 兼容） | 自托管：torch + 1.28GB 权重（CPU 可用，官方标定 CUDA fp16） | 调 API（WebSocket + HMAC） |
| 数据隐私 | 音频上传云端 | **可完全本地/内网** | 音频上传云端 |
| 音频长度 | 单段音频（本实验 0.2–0.6s；长音频成本随 token 增长） | 面向短句/词语（产品） | 单次 ≤5 分钟（字/词/句/篇） |
| 计费 | 按 token（输入 ¥0.8/M、输出 ¥2.7/M） | 开源自托管（成本=算力） | 按次（¥0.0015–0.006/次，见 §5） |
| 单次实测成本 | **¥0.00016**（自由识别） | ≈0（自托管，CPU 50ms/条） | ¥0.0015–0.006 |
| 实测延迟 | 1.2–1.5s（C1）/ 2.0s（全条件均值） | **CPU 中位 47.7ms/条**（load 2.9s） | ≈1–2s/次（6 并发实测 ≈3.5 次/秒） |
| 中文语音覆盖 | 强 | 仅普通话（AISHELL 体系） | 中文（+英文） |
| 本实验角色 | **主方案** | 开源小模型对照 | 商用参考/交叉验证 |

## 1. 评测口径（先说清，避免误读）

| 模型 | 本对比中的运行方式 | 口径 |
|---|---|---|
| Qwen | `qwen3.8-omni-flash`，C1（think off / clean / JSON），exp3 free 一次调用输出 initial/final/tone；检测用派生（自由识别+程序比较） | **自由识别** |
| SDHY | 冻结 XLSR + M1 头（initial 取 CTC 首音素）+ X2 头（final 取最佳非 blank）+ 规则声调（F0 特征，阈值在不相交 512 条上校准），CPU fp32 | **适配后的自由识别**（非其产品原生任务） |
| 讯飞 ISE | 静音填充 300ms + `\ufeff一<拼音>一一` 三字标注卷；声调 4 候选、最小对 2 候选取最高分；检测用 `-total_score` 阈值（半区校准） | **参考已知的候选打分**（非自由识别） |

> 关键：Qwen/SDHY 是自由识别，ISE 是“参考+候选强制选择”。ISE 的 0.922 tone 与
> Qwen 的 0.912 不能简单说“ISE 识别更好”；它是在 4 个候选里选一个。

## 2. 主结果对比（同 2,048 音频）

### 2.1 总体（自由识别，Qwen/SDHY）

| 指标 | Qwen3.8-Omni | SDHY P0-v2 | 差距 |
|---|---:|---:|---:|
| Initial accuracy | **0.962** | 0.600 | +36.2pp |
| Final accuracy | **0.949** | 0.746 | +20.3pp |
| Tone accuracy | **0.912** | 0.699 | +21.3pp |
| Joint accuracy | **0.838** | 0.299 | +53.9pp |
| 派生检测 Error-F1 / FPR | **0.922 / 0.162** | 0.731 / 0.701 | +19.1pp / −53.9pp |

（ISE 无自由识别，故不列此表。）

### 2.2 声调（三模型都能给 tone）

| 设置 | Qwen | SDHY | ISE |
|---|---:|---:|---:|
| 总体 tone（Qwen n=2048；SDHY n=2048；ISE n=512） | 0.912 | 0.699 | **0.922** |
| 三声（tone 3） | 0.842 | **0.438** | **0.750** |
| 二声（tone 2） | 0.809 | 0.891 | 0.961 |
| 一声（tone 1） | ≈1.000 | 0.578 | 0.992 |
| 四声（tone 4） | 0.996 | 0.891 | 0.984 |
| 逐 voice 最弱 | B 0.875 | A 0.574 | **B 0.805** |

> 三声是三者共同短板；Qwen 主要弱在 2/3 声互混，SDHY 连一声都差，ISE 三声 0.75。

## 3. 计算/工程细节

| 项 | Qwen3.8-Omni | SDHY P0-v2 | 讯飞 ISE |
|---|---|---|---|
| 接入方式 | HTTPS，OpenAI 兼容 `/chat/completions`；音频 base64 data URI；`response_format=json_object` | Python 库（`app/`），torch + transformers；编码器 1.28GB + 头 0.9MB | WSS + HMAC-SHA256；`ssb`/`auw` 帧协议 |
| 鉴权 | `DASHSCOPE_API_KEY` + 业务空间 base URL | 无（本地） | APPID/APIKey/APISecret（控制台） |
| 输出 | JSON/文本；无 logprobs | 分数/margin/音素错因/声调形状 | XML：total/phone/tone/流畅/完整分、逐 phone `perr_msg`/`dp_message` |
| 并发/吞吐 | 20 并发实测 ≈9.8 次/秒（79,680 次 / 2h16m） | CPU 单进程 ≈20 条/秒（47.7ms/条）；GPU 官方称 30–90ms/条 | 6 并发实测 ≈3.5 次/秒 |
| 冷启动 | 无（API） | 2.9s（本机 CPU 加载+校验） | 无（API） |
| 硬件 | 无 | CPU 可跑；官方标定 CUDA fp16（CPU 与标定世界不是同一份证据） | 无 |
| 可更新性 | 模型/价格由供应商控制（需固定快照版本） | 权重可完全冻结/自审 | 引擎/价格由供应商控制 |

## 4. 能力矩阵

| 能力 | Qwen | SDHY | ISE |
|---|---|---|---|
| 无参考自由识别（声/韵/调） | ✅ | △（适配后可用但弱） | ❌ |
| 已知 target 发音评测 | ✅（prompt 给 target） | ✅（产品原生） | ✅（产品原生） |
| 逐音素错误类型/分数 | ❌（只有文本） | ✅（margin/VOT/规则） | ✅（perr_msg 细分声韵调） |

| 置信度/概率 | ❌ | ✅（margin 等） | ✅（分数） |
| 长音频/句子/篇章 | ✅（成本随 token 增长） | △（短句/词） | ✅（≤5 分钟，字词句篇） |

## 5. 成本对比（本任务口径）

| 项 | Qwen | SDHY | ISE |
|---|---|---|---|
| 单次调用 | **¥0.000116–0.00016** | ≈0（自有 CPU：约 50ms/条） | ¥0.0015（1 亿次套餐）–¥0.006（20 万次套餐） |
| 自由识别 1 条音频 | **¥0.00016** | ≈0 | 不支持 |
| 声调分类 1 条（4 候选） | **¥0.00016** | ≈0（规则） | ¥0.006–0.024 |
| 最小对 1 侧（2 候选） | **¥0.00016** | ≈0 | ¥0.003–0.012 |
| 检测 1 claim | 派生 0 额外（自由识别复用） | 派生 0 额外 | ¥0.0015–0.006 |
| 本实验实际支出 | mini3 ¥12.37 + mini128 ¥16.78 + 探针 ¥1.45 = **¥30.60** | 0（自有模型；仅算力） | 5,843 次交互（余额 10,000） |
| 同规模 2,048 音频自由识别 | **≈¥0.33** | ≈0 | 不可行 |

盈亏平衡：ISE 在声调 4 候选场景需 **¥0.00004/次**、最小对 2 候选需
**¥0.00008/次** 才与 Qwen 单次成本持平；现最低 ¥0.0015，仍差 **18.8–37.5 倍**。
长音频场景例外：Qwen 音频 token 随时长增长，5 分钟音频输入成本≈¥0.0017，
已接近 ISE 最便宜档，此时按次计费的 ISE 可能更划算（但本数据集是 0.2–0.6s 单音节）。

## 6. 各自弱点（详见 [弱项对比](model-weakness-comparison.md)）

| 模型 | 弱点 | 影响 |
|---|---|---|
| Qwen | m/n 0.858、o/uo 0.804、2/3 声 0.825、en/eng 0.883；检测直接判定 FPR 0.771 | 识别主指标仍最高；但检测必须用派生口径 |
| SDHY | 自由识别适配下 initial 0.600（s 0.062、n 0.161）、三声 0.438、final 0.746（er 0.188）；D 声线 final 0.594 | 只能作“开源小模型/声学特征”参考，不能当主 baseline |
| ISE | 三声 0.750、B 声线 0.805；in/ing 0.625、üe/ie 0.688、ei/ie 0.734、ia/ie 0.828 | 候选打分强但短音节近音韵母弱；且成本高、不支持自由识别 |

互补关系（可直接用于路由/集成）：
* **ISE 补 Qwen**：en/eng（1.000 vs 0.922）、o/uo（0.953 vs 0.812）、z/zh（0.984 vs 0.891）、
  2/3 声（0.875 vs 0.781）、3/4 声（0.984 vs 0.953）；
* **Qwen 补 ISE**：in/ing（0.969 vs 0.625）、üe/ie（0.875 vs 0.688）、ei/ie（0.906 vs 0.734）、
  ia/ie（0.969 vs 0.828）、前后鼻、i/ü；
* **SDHY** 在几乎所有维度最弱，但其“已知 target + 强制对齐 + 质心/VOT”链路
  （本次未接）仍可作为本地可解释评测候选，而不是自由识别 baseline。

## 7. 选型建议

| 场景 | 推荐 | 理由 |
|---|---|---|
| 本研究：大规模识别/检测、要成本可控 | **Qwen3.8-Omni** | 精度最高、单次 ¥0.00016、自由识别/派生检测一次搞定 |
| 商用发音打分、需逐音素诊断、预算充足 | **讯飞 ISE** | 原生 perr_msg/分数、参考已知、成熟；但按次贵、需上云、无自由识别 |
| 离线/内网/数据不出域、短句评测 | **SDHY 栈（原生 target 模式）** | 可全本地、延迟 30–90ms；**不要**用自由识别适配口径 |
| 研究基线三角验证 | 三者都跑 | Qwen 主结果 + ISE 交叉验证 + SDHY 开源对照 |
| 混合路由（性价比 + 补强） | Qwen 主判 + ISE 二意见（仅弱区） | 例如 Qwen 输出 en/eng、o/uo、z/zh、2/3 声时调 ISE；其余不调 |

## 8. 证据与样本量说明

* Qwen：2,048 音频，C1（think off/clean/JSON），prompt v3.1；CI 见
  `docs/results-minimal-128.md`（如 joint [0.822, 0.854]）。
* SDHY：同 2,048 音频自由识别适配；CPU fp32，官方标定 cuda-fp16（不等价）。
* ISE：声调 512 音频 ×4 候选；设计最小对 864 音频侧 ×2；弱对每对 64 音频 ×2；
  检测 256+256 claim；候选打分口径。
* 每对 48–128 条，准确率 95% CI 约 ±7–14pp；表内 5pp 以内差异不应过度解读。
* 所有 Qwen/SDHY/ISE 的原始预测与缓存：
  `results/runs/mini128-v1/`、`results/baseline-sdhy-*`、`results/ise-baseline*`。
